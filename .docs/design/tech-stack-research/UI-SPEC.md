# mvPlayer 界面规范（变体 A · 深灰极简）

> 这是「敲定」后的工具栏与每路控制规格，作为 UI 实现与验收的依据。
> 基准图：`approved.png`（1440×900，四宫格，全部控件可见）。
> 本文只写规格，不用文字去「描述图片构图」；图以文件为准。

## 1. 设计 token

| 项 | 值 |
|---|---|
| 背景 | `#17181A` |
| 工具栏底 | `#1A1C1F` |
| 画格底 | `#1E2023` |
| 分割线 | `#2A2D31`（拖动区 5px，视觉线 1px） |
| 主文字 | `#D7D9DD` |
| 次要文字 | `#8A8F98` |
| 强调色 | `#5B8CFF`（选中、进度、倍速徽标） |
| 强调底 | `rgba(91,140,255,.16)` |
| 圆角 | 4px（按钮/徽标 3px） |
| 字体 | system-ui / Noto Sans CJK SC；正文 13px，控件 12px，辅助 11px |

Fyne 实现约束：不做模糊、阴影、渐变、动画（除进度条与 hover 底色）；图标用矢量路径，不用 emoji。

## 2. 工具栏（50px，单行，左→右）

### 2.1 文件区
1. **`＋ 打开视频`**（主按钮，强调色描边）：系统多选对话框；一次选 N 个文件填入空位；已满 4 路时提示「已是 4 路，请先移除一路」，不覆盖。
2. **`≡ 历史 3`**：下拉列表，每项显示文件名、上次位置、时间；点击以该位置重新打开；底部「清除历史」。计数徽标 = 可恢复条目数。

### 2.2 布局区
7 个图标按钮，按当前路数启用/禁用（禁用态透明度 0.35 + tooltip 说明）：

| 路数 | 可用布局 |
|---|---|
| 1 | 独占 |
| 2 | 左右、上下 |
| 3 | 左+右上、右+左上、四宫格空一格 |
| 4 | 四宫格 |

- 打开文件后按路数自动切到默认布局（2→左右，3→左+右上，4→四宫格）；用户手动选过的布局在本次会话内保持。
- 移除一路后，若当前布局与新路数不符，自动切到该路数的默认布局。
- 选中态：强调色 1px 内描边 + 强调底。

### 2.3 全局区
3. **`«` / `»`**：全部后退/前进一档。
4. **档位下拉**：10s / 30s / 60s / 120s / 自定义（默认 10s）。
5. **`Ⅱ 全部暂停`**：任一路在播 → 全部暂停，按钮变 `▶ 全部播放`；全停 → 全部播放。
- 语义：全局跳转对每路独立执行，各自钳制在 `[0, duration]`；不要求各路时间对齐（各路本来就不同步）。

### 2.4 倍速区
6. **`全局倍速 1.0×`**：预设 0.5 / 0.75 / 1.0 / 1.25 / 1.5 / 2.0 / 3.0 / 4.0 / 6.0 / 8.0 + 自定义；选择后把**每路的基线倍速**都设为该值。
7. **`叠加 − [+] +0.25`**：步长下拉 0.1 / 0.25 / 0.5 / 1.0；`+`/`−` 对每路**当前有效倍速**加/减一个步长，钳制在 `[0.5, 8]`。
- 有效倍速 = clamp(基线 + 叠加, 0.5, 8)；底部状态栏同时显示「基线列表」与「叠加后列表」。
- 单路下拉改的是该路基线；叠加值不变，立即反映到有效倍速。

### 2.5 右侧
8. **`⚙`**：设置对话框——自定义倍速列表（逗号分隔，默认如上）、自定义跳转档位、历史记录开关、默认布局、是否在打开时自动恢复上次进度。

## 3. 每路 HUD（画格底部，38px，常显）

左→右：
1. `当前时间 / 总时长`（等宽数字，`00:12:34 / 01:40:12`）
2. 进度条（3px，可点击/拖动 seek；hover 变粗到 5px）
3. 档位下拉（10s / 30s / 60s / 120s / 自定义，**每路独立**，默认跟随全局档位）
4. `−` / `Ⅱ`（或 `▶`）/ `＋`：该路按自己的档位后退/播放暂停/前进
5. 倍速下拉（0.5–8 预设 + 自定义，**每路独立**）
6. `✕`：移除该路，画格变空位

画格左上：文件名（超长省略，hover 显示全名）；右上：当前有效倍速徽标（如 `2.0×`，强调色）。

## 4. 空位与 0 路

- 空位：虚线描边 `#34383D`，居中「空位 · 拖入视频」；点击打开文件；也接受拖拽文件到画格。
- 0 路：整块舞台一个空位，居中提示「打开视频开始」+ 快捷键提示。
- 文件打不开/编码不支持：该画格显示错误文案（文件名 + 原因 + 「移除」），不静默黑屏。mpv 能解全部常见编码，此路径主要防损坏文件。

## 5. 历史记忆

- 键：绝对路径 + 文件大小 + mtime（防同名替换）；值：位置、时长、最后播放时间。
- 写入：每 5 秒、暂停时、关闭/移除时。
- 读取：打开文件命中则 seek 到记录位置，并弹 3 秒提示「已从 12:34 继续」；可在设置关闭自动恢复。
- 存储：`os.UserConfigDir()/mvPlayer/history.json`（Windows `%AppData%`，Linux `~/.config`）。

## 6. 键盘

| 键 | 作用 |
|---|---|
| `Space` | 全局暂停 / 恢复（4 路同时） |
| `←` / `→` | 全局后退 / 前进 **10 秒（固定，不跟随档位下拉）** |
| `1`–`7` | 切换布局（不可用则忽略） |
| `Delete` | 移除当前聚焦画格 |
| `Ctrl+O` | 打开视频 |

## 7. 验收对应

| 需求 | 规范落点 |
|---|---|
| 1～4 路、布局 | §2.2 布局区 + §3 画格 + §4 空位 |
| 每路独立倍速 0.5–8 | §3 倍速下拉 + §2.4 有效倍速公式 |
| 每路独立 ±10/30/60/120 | §3 档位下拉与 ± 按钮 |
| 全局暂停/跳转/叠加倍速 | §2.3、§2.4 |
| 历史播放记忆 | §5 |
| 拖分割线 + 自适应 | §1 分割线 token（5px 拖动区、10%–90%、双击复位 50/50） |
| 美观简洁、少 AI 感 | §1 token + 无渐变/阴影/动画 |
